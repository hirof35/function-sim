# 📊 自由入力式・関数計算シミュレータ (Function Simulator in Rust)

Rust と GUI フレームワーク `egui` (`eframe`) を用いて開発された、インタラクティブな関数計算・可視化シミュレータです。
一次関数、二次関数から、三次高次関数までのグラフをリアルタイムに描画・シミュレーションできます。

## ✨ 主な機能

- **自由な数式カスタマイズ**: 3次・2次・1次の係数および定数項をテキストボックスから自由に入力可能。
- **動的なX軸範囲指定**: 描画したい $x$ の範囲（最小値・最大値）を直接数値入力で指定可能。
- **高速なリアルタイム描画**: Rust の高いパフォーマンスを活かし、数値入力と同時にカクつきなくグラフを再描画。
- **インタラクティブなグラフ操作**: `egui_plot` により、マウスドラッグでのグラフ移動や、ホイールスクロールによる拡大・縮小（ズーム）に対応。
- **日本語 & エラー防止機能**: OSの標準フォントを自動読み込みし、日本語表示に対応。また、描画範囲の逆転時には警告を表示する安全設計。

## 🚀 動作環境・必要なもの

- **Rust / Cargo**: 2021 edition 以降
- **OS**: Windows, macOS, Linux (各OSの標準日本語フォントを自動で探索・適用します)

依存関係の設定 (Cargo.toml)Cargo.toml の [dependencies] に以下を追加します。Ini, TOML[dependencies]

コードの配置src/main.rs にシミュレータのソースコードを貼り付けます。アプリケーションの起動Bashcargo run --release
(※ 描画パフォーマンスを最大化するため、--release フラグを付けての実行を推奨します)💡 技術的な特徴（数理ロジック）本シミュレータでは、高次多項式の評価に ホーナー法（Horner's method） を採用しています。通常の累乗計算（$x^3$ や $x^2$ など）を愚直に行うのに比べ、乗算の回数を劇的に減らすことができるため、描画スループットが非常に高いのが特徴です。$$f(x) = dx^3 + ax^2 + bx + c \implies ((dx + a)x + b)x + c$$Rustのイテレータ機能（.iter().rev().fold(...)）を用いて、このホーナー法をわずか3行でエレガントに実装しています。📜 ライセンスこのプロジェクトは MIT ライセンスの下で公開されています。
